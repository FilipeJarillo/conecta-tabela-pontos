# Tabela de pontuação — Conecta Enterprise (parceiros)

Página publicada pelo GitHub Pages e embedada por iframe na página Campanha do portal Conecta Enterprise.

- `index.html`: a tabela (smartphones e tablets), num arquivo só, sem requisições externas.
- Gerada a partir do gerador em `cerebro/02_Projetos/Conecta Enterprise (Samsung)/Tabela de pontuacao - embed/gerador/`.
- Para atualizar: rodar o gerador, copiar o HTML para `index.html`, commit e push. O site atualiza em 1 a 2 minutos.
